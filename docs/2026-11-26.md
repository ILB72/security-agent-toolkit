## Computer-019 · 패킷 경로

### 같은 망 본보기
- 내 PC (10.0.1.10) → L2 스위치 → 옆자리 PC (10.0.1.11)

### 파일 서버의 망 판정과 근거
- **PC 주소:** `10.0.1.10/24` → 네트워크 부분: `10.0.1`
- **파일 서버 주소:** `10.0.2.20/24` → 네트워크 부분: `10.0.2`
- **판정:** `두 주소의 앞 세 묶음(10.0.1 vs 10.0.2)이 다르므로, PC와 파일 서버는 **다른 망**에 속한다.`

### 파일 서버까지의 경로
- `PC (10.0.1.10) → L2 스위치 (SW VLAN10) → L3 스위치 (L3-1) → L2 스위치 (SW VLAN20) → 파일 서버 (10.0.2.20)`

### 같은 망의 경로와 달라진 점
- `같은 망은 L2 스위치만 거치지만, 다른 망은 **L3 스위치(라우터 역할)**를 반드시 거쳐야 한다. L2 스위치는 같은 망 안에서만 전달하고, L3 스위치는 서로 다른 IP 네트워크 사이로 패킷을 넘겨주기 때문이다.`

### 어느 장비가 다른 망으로 넘기는지
- `**L3 스위치 (L3-1)**가 서로 다른 VLAN(네트워크) 사이를 연결하여 패킷을 넘겨준다.`
