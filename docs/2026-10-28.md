## Network-003 · 여러 값을 하나씩 처리하기

### 한 일
- agent_core에 assignment_03_f1.py, assignment_03_f2.py 작성
- 리스트(users)를 for 반복문으로 하나씩 꺼내 출력
- range(1, 4)로 1~3까지 반복 출력

### 확인한 결과
- F1: users = ["kim01","lee02","park03"] → kim01 / lee02 / park03 한 줄씩 출력
- F2: range(1, 4) → 1 / 2 / 3 출력 (끝값 4는 출력되지 않음)

### 새로 알게 된 점
- 리스트는 값을 순서대로 담고, 번호(인덱스)는 0부터 센다. users[0]이 첫 번째
- for 값 in 목록: 목록에서 값을 하나씩 꺼내며 반복. 콜론(:) + 들여쓰기 4칸
- range(시작, 끝)은 끝값을 포함하지 않는다. range(1, 4)는 1,2,3만 생성
- 인덱스 범위를 벗어나면 IndexError: list index out of range
