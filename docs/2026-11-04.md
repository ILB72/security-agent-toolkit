## Computer-007 · 명령어로 깃허브에 올리기

### 오늘 새로 쓴 명령
git config, git add, git commit, git push

### 찾아보고 알게 된 것
- **add와 commit과 push는**: 
  - add: 내 PC에서 커밋할 파일을 고르는 단계 (staging)
  - commit: 고른 파일들을 내 PC에 하나의 기록(버전)으로 저장하는 단계
  - push: 내 PC에 저장된 커밋 기록을 원격 저장소(GitHub)로 보내는 단계
- **untracked · tracked · staged는**:
  - untracked: git이 한 번도 기억하지 못한 새 파일 (빨간색)
  - tracked: 한 번이라도 커밋되어 git이 기억하는 파일 (수정 시 modified로 표시)
  - staged: `git add`를 통해 다음 커밋에 포함되기로 선택된 상태 (초록색)
