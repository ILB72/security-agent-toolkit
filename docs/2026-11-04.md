## Computer-007 · 명령어로 깃허브에 올리기

### 오늘 새로 쓴 명령
git config, git add, git commit, git push

### 찾아보고 알게 된 것
- **add와 commit과 push는**: 
  - add: 내 PC에서 커밋할 파일을 고르는 단계 (staging)
  - commit: 고른 파일들을 내 PC에 하나의 기록(버전)으로 저장하는 단계
  - push: 내 PC에 저장된 커밋 기록을 원격 저장소(GitHub)로 보내는 단계
- **untracked · tracked · staged는**:
  - untracked: git이 한 번도 기억하지 못한 새 파일 (빨간색)
  - tracked: 한 번이라도 커밋되어 git이 기억하는 파일 (수정 시 modified로 표시)
  - staged: `git add`를 통해 다음 커밋에 포함되기로 선택된 상태 (초록색)

## Computer-008 · Wireshark 설치하고 새 과목 폴더 만들기

### 오늘 설치한 것
Wireshark (Npcap 함께)

### 찾아보고 알게 된 것
- **보안 담당자가 패킷을 직접 열어 보는 이유는**: 네트워크로 오가는 실제 데이터를 눈으로 확인하여, 알림(경보)만으로는 알 수 없는 침해 흔적이나 비정상 통신을 분석하기 위해서다.
- **패킷은**: 네트워크를 통해 전송되는 데이터의 작은 조각(단위)이다.
- **Npcap은**: 윈도우 환경에서 Wireshark가 네트워크 인터페이스의 패킷을 캡처할 수 있도록 도와주는 드라이버(부품)다.
- **| (파이프)는**: 앞 명령의 출력 결과를 뒤 명령의 입력으로 넘겨주는 연결 기호다.
