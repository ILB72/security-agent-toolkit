## 찾아보고 알게 된 것
- 서버·보안관제는 대부분 리눅스 기반이라 화면 없이 명령어로 다룬다. 리눅스는 서버 운영에 이점이 많아 널리 쓰인다.
- GitHub는 작업물 공유와 변경 이력(히스토리) 관리, 협업·검토·복구를 위해 쓴다.
- 터미널 = 명령어로 컴퓨터와 소통하는 창
- 경로(path) = 파일·폴더의 위치를 나타내는 표기
- Git Bash = 윈도우(cmd)에서 리눅스/유닉스 bash 명령을 쓸 수 있게 해 주는 도구
