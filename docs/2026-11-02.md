## Computer-006 · 내 폴더를 깃허브 저장소와 연결하기

### 오늘 새로 쓴 명령
git init, git remote add, git fetch, git reset, git branch -u, git status

### 찾아보고 알게 된 것
- **저장소와 내 폴더는**: 원격 저장소(GitHub)는 공유/백업 공간이고, 내 PC 폴더는 로컬 작업 공간이다. git 명령어를 통해 이 둘을 동기화한다.
- **원격 저장소(remote)**: 내 PC에서 바라보는 GitHub의 저장소를 뜻하며, 보통 `origin`이라는 이름으로 등록해 쓴다.
