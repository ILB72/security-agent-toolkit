## Computer-010 · 파일 만들고 옮기고 지우기

### 찾아본 것
- **서버에서 로그를 옮기고 백업하는 방법**: 서버는 GUI가 없어 `cp`(복사), `mv`(이동/이름변경), `rm`(삭제) 명령어를 사용해 파일을 관리하고 백업한다.

### 오늘 새로 쓴 명령
touch, cp, mv, rm, Tab 자동 완성

### 찾은 옵션
- 폴더째 복사: `-r`
- 덮어쓰기 전에 묻기: `-i`
- 폴더째 지우기: `-r`

### mv 의 두 가지 쓰임
- 이름 바꾸기: `mv b.log c.log`
- 옮기기: `mv c.log backup/`

### 막힌 것
해당 없음

### 다음에 확인할 것
- `git diff`로 커밋 전 변경 사항을 터미널에서 미리 확인하는 방법

### 오늘의 한 줄
파일 관리 명령어의 위험성을 알고, -i와 같은 안전 옵션을 습관화하자.
