## Computer-005 · 무료 Gemini API 키를 발급받아 보관하기

### 한 일
- Google AI Studio에서 개인 Gmail로 Gemini API 키 발급
- `security-agent-toolkit` 루트에 `.env` 파일을 만들어 키 보관
- `.gitignore`에 `.env`를 추가하여 깃허브 업로드 차단 확인
- `curl` 명령어로 키가 살아있는지 테스트

### 찾아보고 알게 된 것
- **API 키는**: 서버에 요청을 보낼 때 "허가된 사용자"임을 증명하는 비밀번호 같은 역할을 한다. 유출되면 과금이나 악용 피해가 발생한다.
- **무료 등급(free tier)은**: 비용 없이 쓸 수 있지만, 분당 요청 횟수(15회) 등 호출 한도에 제한이 걸린다.
- **보안 담당자가 다루는 서버는**: 대부분 리눅스 기반이다.
- **깃배시를 쓰면**: 윈도우에서 리눅스 서버와 동일한 명령어 환경을 미리 연습하고 사용할 수 있다.

### 키가 틀렸을 때와 키가 없을 때의 차이
- **키가 틀렸을 때**: `401 UNAUTHENTICATED` (인증 실패 - 키는 줬으나 유효하지 않음)
- **키가 없을 때(헤더 누락)**: `403 PERMISSION_DENIED` (권한 없음 - 인증 수단 자체가 없음)
