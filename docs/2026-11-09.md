## Network-011 · CSV·JSON으로 작은 보고서 만들기

### 한 일
- agent_core에 assignment_11_f1.py, assignment_11_f2.py 작성
- `csv.DictReader`를 사용해 헤더가 있는 CSV 파일을 딕셔너리 형태로 읽고, 조건에 맞는 데이터 카운트
- `json` 모듈을 사용해 JSON 파일을 읽고, 집계한 결과를 문자열로 만들어 `summary.txt` 파일로 저장

### 확인한 결과
- F1: `gichan_input.csv`를 읽어 result가 "FAIL"인 행의 개수 2를 정상 출력 확인
- F2: `gichan_input.json`을 읽어 전체 데이터 3건 중 실패가 2건임을 확인하고, "전체 3건, 실패 2건"을 `summary.txt`에 저장 및 출력 확인

### 새로 알게 된 점
- CSV 파일은 `csv.reader`로 읽으면 인덱스(번호)로 접근해야 하지만, `csv.DictReader`를 쓰면 첫 줄(헤더)을 키로 사용해 `row["result"]`처럼 이름으로 직관적으로 접근할 수 있다.
- JSON 데이터를 파이썬으로 불러오면 리스트와 딕셔너리 형태가 되므로, 반복문과 `len()`을 활용해 쉽게 집계할 수 있다.
