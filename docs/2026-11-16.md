## Computer-012 · 서버에서 파일 속 글 고치기 (vim)

### 찾아본 것
- **서버에서 설정 파일을 고치는 방법**: GUI가 없는 리눅스 서버에서는 터미널 기반 편집기인 `vim`을 사용해 설정 파일을 열고 수정한다.

### 오늘 새로 쓴 명령
vim

### vim 으로 한 것
- 입력 모드로 들어가는 키: `i`
- 일반 모드로 돌아오는 키: `Esc`
- 저장하고 나가는 명령: `:wq`
- 저장 없이 나가는 명령: `:q!`
- 지운 것을 되돌리는 키: `u`
