## Computer-014 · Docker Desktop 윈도 설치 확인

### 한 일
- Docker Desktop이 이미 설치되어 있음을 확인 (버전 29.9.3)
- `docker ps` 명령으로 현재 실행 중인 컨테이너(postgres:16-alpine) 확인
- `docker run hello-world` 명령으로 설치 정상 동작 확인
- `docker ps -a` 명령으로 종료된 컨테이너를 포함한 전체 기록 확인

### 확인한 결과
- `docker --version`: Docker version 29.9.3, build 5457199
- `docker ps`: postgres:16-alpine 컨테이너가 실행 중(Up)임을 확인
- `docker run hello-world`: "Hello from Docker!" 메시지 정상 출력 확인 (이미지 다운로드 및 실행 성공)
- `docker ps -a`: hello-world 컨테이너가 Exited (0) 상태로 목록에 추가됨을 확인

### 새로 알게 된 점
- `docker ps`는 현재 실행 중인 컨테이너만 보여주고, `docker ps -a`는 종료된 컨테이너까지 모두 보여준다.
- `hello-world` 이미지를 실행하면 Docker 클라이언트가 데몬에 요청하고, 데몬이 이미지를 받아 컨테이너를 생성해 실행한 뒤 결과를 터미널로 보내는 과정을 확인할 수 있다.
